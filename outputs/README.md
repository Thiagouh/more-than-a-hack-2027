# Resultados locais

Use esta pasta para previsões em `submissions/`, relatórios de avaliação e features intermediárias.
Somente este README é destinado ao Git. Os resultados são ignorados.

Exemplo, a partir da raiz:

```bash
python starter/baseline.py --out outputs/submissions/baselines
python evaluation/run_evaluation.py --results outputs/submissions/baselines --out outputs/evaluation
```

Registre commit, configuração, origem dos dados e ambiente de cada experimento. Não publique
tracking, clipes ou derivados privados sem conferir os termos da competição.
